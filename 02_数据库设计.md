# V1 开发文档 02 · 数据库设计

> **数据库**：SQLite（WAL 模式）。DDL 与字段类型保持 PostgreSQL 兼容（迁移注意见第 5 节）。
> **数据真源**：课时卡结构字段来自《课时安排定版 v3》第三节；本 DDL 是建表唯一依据。
> **班期模型**：已拍板多班期隔离（PRD 决策 D4）——课程结构（module/lesson_card/material）全局共享，学员数据（student/schedule/activity/email_log）按班期隔离。
> **V1 不建表**：作业提交 Submission、批改反馈 Feedback、资料文件 FileObject（V2 预留，见第 6 节）。

---

## 1. ER 总览

```
module 1──n lesson_card 1──n material
              │
              ├──n schedule n──1 student n──1 cohort
              │        │            │
              │        └────────────┴── activity（学员×课时：预习已读/录播完成）
              │
              └──n email_log n──1 student

staff_user（独立，与 student 无关联）
email_token（验证/重置，→ student）
config（站点 key-value：刷题清单链接等）
```

读写规模预估：学员 ≤ 50 人，课时卡 42 张，schedule ≈ 50×15=750 行，email_log ≈ 50×30=1500 行/期。SQLite 完全够。

## 2. 建表 DDL

### 2.1 module 课程模块

```sql
CREATE TABLE module (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  code        TEXT NOT NULL UNIQUE,      -- 'M1'..'M4'，'FLEX'（答疑）
  title       TEXT NOT NULL,             -- 'CS 理论基础'
  subtitle    TEXT DEFAULT '',           -- 'C01–C04 · 4 节 1v1'
  sort_order  INTEGER NOT NULL
);
```

### 2.2 lesson_card 课时卡（全局唯一，种子数据预填）

```sql
CREATE TABLE lesson_card (
  id              INTEGER PRIMARY KEY AUTOINCREMENT,
  module_id       INTEGER NOT NULL REFERENCES module(id),
  code            TEXT NOT NULL UNIQUE,   -- C01..C04 / E01..E05 / T01..T03 / D01..D27 / V01..V03
  title           TEXT NOT NULL,          -- '计算机网络' / '论坛 v1 · 能用版'
  lesson_type     TEXT NOT NULL CHECK (lesson_type IN ('1v1','recorded','validation','flex')),
  duration_min    INTEGER,                -- 课内时长（1v1/验收用；录播为单讲时长）
  effort_note     TEXT DEFAULT '',        -- 课后投入，如 '1–3 h'
  content_summary TEXT NOT NULL,          -- 内容一句话（列表页展示）
  project_stage   TEXT DEFAULT '',        -- E 线版本标签：'论坛 v1 · 能用' 等
  preview         TEXT,                   -- JSON：{"intro","questions":[..],"keywords":[..],"message_ref"}
  homework_def    TEXT DEFAULT '',        -- 作业定义（V1 只读展示）
  deps            TEXT DEFAULT '',        -- 硬依赖（当前无）
  part_group      TEXT,                   -- 录播部分组：'D-1'(D01-06)/'D-2'(D07-19)/'D-3'(D20-27)
  video_url       TEXT DEFAULT '',        -- 录播视频外链（V1 即外部链接）
  sort_order      INTEGER NOT NULL
);
CREATE INDEX idx_lesson_module ON lesson_card(module_id, sort_order);
```

`preview` JSON 结构约定：

```json
{
  "intro": "开场 20 分钟 ML 速通 → 问题链串讲：CNN/RNN/Attention …",
  "questions": [
    "Attention 能并行而 RNN 不能，代价是什么？",
    "位置信息在哪一层注入、为什么要？",
    "KV Cache 缓存了什么、省了什么？"
  ],
  "keywords": ["归纳偏置", "门控", "QKV", "RoPE", "KV Cache"],
  "message_ref": "课程预习消息汇编_2.0.md#T01"
}
```

### 2.3 material 资料清单（外链，V1 无站内文件）

```sql
CREATE TABLE material (
  id             INTEGER PRIMARY KEY AUTOINCREMENT,
  lesson_card_id INTEGER NOT NULL REFERENCES lesson_card(id),
  title          TEXT NOT NULL,           -- '《大规模语言模型》架构章'
  mat_type       TEXT NOT NULL CHECK (mat_type IN ('book','handout','code','checklist','quiz')),
  required       INTEGER NOT NULL DEFAULT 1,   -- 1 必发 / 0 选发
  url            TEXT NOT NULL,           -- 外部链接（网盘/在线文档）
  sort_order     INTEGER NOT NULL DEFAULT 0
);
```

### 2.4 cohort 班期

```sql
CREATE TABLE cohort (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  name       TEXT NOT NULL UNIQUE,        -- '202610 期'
  start_date DATE NOT NULL,
  status     TEXT NOT NULL DEFAULT 'active' CHECK (status IN ('active','closed'))
);
```

### 2.5 student 学员

```sql
CREATE TABLE student (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  email         TEXT NOT NULL UNIQUE,     -- 即账号即通知地址
  password_hash TEXT NOT NULL,            -- bcrypt
  name          TEXT NOT NULL,
  cohort_id     INTEGER NOT NULL REFERENCES cohort(id),
  status        TEXT NOT NULL DEFAULT 'pending'
                CHECK (status IN ('pending','active','suspended','graduated')),
               -- pending=已注册未激活；active=在读；suspended=休学；graduated=结课
  created_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  last_login_at DATETIME
);
CREATE INDEX idx_student_cohort ON student(cohort_id);
```

**白名单实现**：运营后台导入 `whitelist` 表（或 config JSON）。学员注册时校验邮箱在白名单且未注册过，成功注册后白名单条目标记已用。

```sql
CREATE TABLE whitelist (
  id        INTEGER PRIMARY KEY AUTOINCREMENT,
  email     TEXT NOT NULL UNIQUE,
  cohort_id INTEGER NOT NULL REFERENCES cohort(id),
  used_by   INTEGER REFERENCES student(id),   -- 注册后回填
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

### 2.6 schedule 排期（学员 × 课时卡，班期隔离核心）

```sql
CREATE TABLE schedule (
  id             INTEGER PRIMARY KEY AUTOINCREMENT,
  student_id     INTEGER NOT NULL REFERENCES student(id),
  lesson_card_id INTEGER NOT NULL REFERENCES lesson_card(id),
  scheduled_at   DATETIME,                -- NULL = 未排期
  meeting_link   TEXT DEFAULT '',         -- 上课/会议链接
  status         TEXT NOT NULL DEFAULT 'planned'
                 CHECK (status IN ('planned','scheduled','done','skipped')),
                 -- planned=未排；scheduled=已排；done=已上课；skipped=跳过/免修
  created_by     INTEGER REFERENCES staff_user(id),
  updated_at     DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE (student_id, lesson_card_id)
);
CREATE INDEX idx_schedule_next ON schedule(student_id, status, scheduled_at);
```

### 2.7 activity 行为记录

```sql
CREATE TABLE activity (
  id             INTEGER PRIMARY KEY AUTOINCREMENT,
  student_id     INTEGER NOT NULL REFERENCES student(id),
  lesson_card_id INTEGER NOT NULL REFERENCES lesson_card(id),
  act_type       TEXT NOT NULL CHECK (act_type IN ('preview_read','recorded_done')),
  acted_at       DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE (student_id, lesson_card_id, act_type)
);
```

### 2.8 email_token 验证/重置/直达 token

```sql
CREATE TABLE email_token (
  id         INTEGER PRIMARY KEY AUTOINCREMENT,
  student_id INTEGER NOT NULL REFERENCES student(id),
  token      TEXT NOT NULL UNIQUE,        -- secrets.token_urlsafe(32)
  purpose    TEXT NOT NULL CHECK (purpose IN ('verify','reset','magic_link')),
  expires_at DATETIME NOT NULL,           -- verify/reset 24h；magic_link 7 天
  used_at    DATETIME                     -- 一次性：用过即废
);
```

### 2.9 email_log 邮件记录

```sql
CREATE TABLE email_log (
  id             INTEGER PRIMARY KEY AUTOINCREMENT,
  student_id     INTEGER REFERENCES student(id),
  to_email       TEXT NOT NULL,
  mail_type      TEXT NOT NULL CHECK (mail_type IN
    ('verify','reset','welcome','schedule_confirm','schedule_change','preview_reminder','class_reminder')),
  lesson_card_id INTEGER REFERENCES lesson_card(id),
  subject        TEXT NOT NULL,
  status         TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending','sent','failed')),
  retry_count    INTEGER NOT NULL DEFAULT 0,
  error_msg      TEXT,
  sent_at        DATETIME,
  created_at     DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
CREATE INDEX idx_email_dedup ON email_log(student_id, mail_type, lesson_card_id, created_at);
```

### 2.10 staff_user / config

```sql
CREATE TABLE staff_user (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  email         TEXT NOT NULL UNIQUE,
  password_hash TEXT NOT NULL,
  name          TEXT NOT NULL,
  role          TEXT NOT NULL DEFAULT 'staff',   -- V1 单角色
  created_at    DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE config (
  key        TEXT PRIMARY KEY,            -- 'brush_sop_url'（刷题清单链接）、'qa_contact'（答疑预约邮箱）等
  value      TEXT NOT NULL,
  updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

## 3. 种子数据（`server/app/seeds/`）

| 内容 | 数量 | 来源 |
|---|---|---|
| module | 5 条（M1–M4 + FLEX） | 定版 v3 第一节 |
| lesson_card | **42 张**：C×4 + E×5 + T×3 + D×27 + V×3 | 定版 v3 第三节逐课时明细 |
| material | 按定版 v3 各课时「资料」列预填（链接先占位，运营后台补真实 URL） | 定版 v3 + 预习材料清单 |
| cohort | 1 条：202610 期 | 当前实际 |
| staff_user | 1 条：ADMIN_BOOTSTRAP_EMAIL，首登强制改密 | — |
| whitelist | 当期学员邮箱 | 运营导入 |

种子脚本要求**幂等**（按 code/name upsert），结构变更（如 Demo 线回归）时改 `lessons_seed.json` 重跑即可，不动表结构。

## 4. 关键查询口径（与 PRD 对齐，勿各写各的）

| 口径 | SQL 逻辑 |
|---|---|
| 下一节课 | `schedule WHERE student_id=? AND status='scheduled' AND scheduled_at>now ORDER BY scheduled_at LIMIT 1` |
| 1v1 进度分母 | `lesson_type IN ('1v1','validation')` 共 **15**；分子 = 该学员 `schedule.status='done'` 计数 |
| 录播进度分母 | `lesson_type='recorded'` 共 **27**；分子 = 该学员 `activity.act_type='recorded_done'` 计数 |
| 预习解锁 | `scheduled_at - INTERVAL 2 DAY <= now`（排期时间推导，不单独存字段） |
| 课时展示状态 | 优先 schedule.status；未排期时 = `未解锁`；`scheduled 且 T-2 已到 且无 preview_read` = `预习中` |
| 预习已读率（运营） | 分母 = 已到 T-2 的已排课时数；分子 = 对应 activity 有 preview_read 的数 |
| 防重发邮件 | 发送前查 `email_log WHERE student_id=? AND mail_type=? AND lesson_card_id=? AND created_at > now-24h` |

## 5. SQLite → PostgreSQL 迁移注意（V2 后按需执行）

- `AUTOINCREMENT` → `GENERATED ALWAYS AS IDENTITY`（Alembic 迁移脚本改写）
- `preview` 等 JSON 文本列 → `JSONB`
- 时间统一存 **UTC ISO8601**，展示层转 `Asia/Shanghai`（V1 就按此执行，不留隐患）
- SQLite 单写连接 + WAL 已满足 V1 并发；迁移仅在学员量 ×10 或接入站内文件（V2）时触发

## 6. V2 预留设计（本期不建表，避免误开发）

```
submission（作业提交）：student_id, schedule_id, link, note, submitted_at, replaced_by
  —— 一次提交一条记录，重新提交追加不覆盖（PRD v1.0 遗留规则，V2 沿用）
feedback（批改反馈）：submission_id, comment, result(pass/redo), created_at
file_object（站内资料）：material_id, storage_key, size, content_type, uploaded_by
  —— 仅当资料从外链转站内托管时启用
```
